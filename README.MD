# 🌙 Dream Journal

> "Write down your dreams before you forget it."

## 🌟 Overview

The **Dream Journal** is a dedicated tool for recording, organizing, and reflecting upon your dreams and nightmares. By encouraging immediate entry upon waking, the app helps users improve their dream **recall** and gain deeper **insights** into their subconscious mind through consistent data logging.

This project is built to be simple, fast, and reliable, transforming a fleeting memory into a durable, searchable record.

---

## ✨ Core Features

| Feature | Description |
| :--- | :--- |
| **Instant Capture** | Quick entry form to jot down the core elements of a dream immediately. |
| **Searchable Database** | Find specific dreams based on keywords, dates, or custom tags. |
| **Thematic Analysis** | Helps identify recurring themes, characters, or emotions over time. |
| **Offline Access** | (If applicable) Log dreams even without an internet connection. |
| **Simple UI/UX** | Focused on minimal friction between waking up and logging the memory. |

---

## 💻 Tech Stack

This project is powered by the following technologies.

* **Frontend:** Next.js (React + TypeScript)
* **Backend:** Next.js API Routes,NODE.JS (Server Components / Route Handlers)
* **Database:** MySQL (via Drizzle ORM)
* **Styling:** Tailwind CSS
* **State Management:** None (currently not using external state libraries)

## 🛠 Getting Started

Follow these steps to set up and run the project on your local machine.

### Prerequisites

Ensure you have the following software installed:

* **Git**
* **Node.js & npm** (or **Yarn**)

### 1. Installation

Clone the repository and navigate into the project directory:

git clone [https://github.com/Dhruv6227/Dream-Journal.git](https://github.com/Dhruv6227/Dream-Journal.git)
cd Dream-Journal

Install the project dependencies:

npm install 
# or 
# yarn install

### 2\. Configuration

Create a configuration file to handle environment-specific variables:

touch .env

Populate the `.env` file with your necessary keys and settings:


# Example: Database connection
DATABASE_URL=your_local_db_connection_string

# Example: API Key
GOOGLE_API_KEY=your_optional_service_key
```

### 3\. Running the App

Start the development server:

```bash
npm run dev 
# or 
# npm start
```

The application should now be running at `[e.g., http://localhost:3000]` or in your mobile simulator/device.
